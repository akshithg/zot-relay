Installation guide for agents

Agent setup is a local preview. The public guide will be available after the new repository is created and these changes are on GitHub.

A note for your agent

Install Zot Relay for this agent using https://raw.githubusercontent.com/akshithg/zot-relay/main/INSTALL.md. Verify the connection without changing my Zotero library.

Your agent needs local command access and a client that supports stdio MCP. If it has no computer access, it will ask you to install the Zotero plugin through Tools → Plugins. Reload your client’s MCP connections when setup finishes.

Before changing your library

Zot Relay is designed for a personal machine with trusted local apps. Your agent can change your Zotero library and access files through the connection. There is no sandbox or client authentication.

Give your agent clear limits, back up affected data before bulk writes, and verify the result in Zotero. Zot Relay has no undo. A timeout does not cancel a script; check what changed before retrying.
